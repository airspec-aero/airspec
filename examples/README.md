# Overview
This directory contains different examples of using the spec to configure different rules. One directory per ruleset, and a "general" directory for ad hoc rule examples.

# File Types
Different file types in the directories:
- .json: specification files.
- .mermaidjs.txt: refer to the same rule, but converted from JSON into the [Mermaid JS](https://github.com/mermaid-js/mermaid) flowchart code format (using a custom plug-in):
    - Illustrates how plug-ins allow you to visualise the same spec however you want.
    - To view it yourself, go to [mermaid.live](https://mermaid.live/) and paste the contents of the file into the "Code" panel.
