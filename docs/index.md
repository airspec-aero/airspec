# AirSpec

An open, vendor-neutral way to describe airline crew rules and their meaning.

## The problem

Crew compliance and payroll rules are spread across regulations, agreements, local knowledge and vendor-specific implementations. Moving to a new system often means interpreting and implementing the same rules again.

## The idea

AirSpec proposes a shared, machine-readable specification that domain experts can review and different systems can use. A rule should retain its meaning and its connection to the source document when it moves between tools.

> Regulation, agreement or airline policy → shared rule model → human verification → system implementation

## Follow the work

The project is at an early stage. We are exploring how to describe rules precisely, compare interpretations and make changes easier to understand.
